# CursorBar UI redesign

วันที่: 2026-10-26

ออกแบบใหม่ทั้งเมนูบาร์และแผงที่กดเปิด ข้อมูลเดิมยังอยู่ เพิ่มเฉพาะสิ่งที่อ่านจากเซสชัน Cursor ในเครื่องได้ และใช้เวลาของเครื่อง

## แนวทางที่เลือก

ใช้วัสดุ Liquid Glass ของระบบ เป้าหมายต่ำสุดของแอปจึงเป็น macOS 26 บน macOS 27 วัสดุนี้ได้ความฝ้า ขอบแสง และมุมโค้งของ Golden Gate ตามระบบเอง

ทางที่ไม่ได้ใช้: คง macOS 14 แล้วปลอมกระจกด้วยวัสดุเบลอ เพราะไม่ใช่ Liquid Glass ที่อนุมัติไว้ และไม่ตามสไลเดอร์ความฝ้าของระบบ

แผง ปุ่มรีเฟรช และไฮไลต์ของไอคอนตอนแผงเปิด ใช้กระจกของระบบ ความฝ้าตามค่าที่ผู้ใช้ตั้งใน System Settings ถ้าเปิด Reduce Transparency แผงฝ้าขึ้นจนอ่านตัวอักษรได้ เนื้อหาในแผงไม่ซ้อนกระจกทับกระจก

## เมนูบาร์

แถบเมนูโปร่ง สัญลักษณ์เป็นเกจเส้นแบบไอคอนสถานะของ macOS 27 สีเดียวกับตัวอักษรระบบ ขาวเมื่อด้านหลังมืด ดำเมื่อด้านหลังสว่าง ตัวเลขใช้ฟอนต์เดียวกับนาฬิกา

สถานะใช้สีเฉพาะจุด

- มีเอเจนต์รอตอบ: ป้ายเหลืองพร้อมจำนวน ทับมุมไอคอน
- มีเอเจนต์ทำงาน และไม่มีงานรอตอบ: ไอคอนธรรมดา ไม่มีป้ายเลข
- ใช้เกินโควต้า: เปอร์เซ็นต์โควต้าเป็นสีแดง
- ไม่มีเอเจนต์และไม่มีงานรอตอบ: ไอคอนกับ 0% สีจาง

ตอนแผงเปิด ไฮไลต์หลังไอคอนใช้การไฮไลต์ของแถบเมนูระบบ ไม่ได้วาดแคปซูลซ้ำถ้าแถบเมนูไฮไลต์ให้อยู่แล้ว

สวิตช์ในตั้งค่ามีผลเฉพาะเมนูบาร์ แผงยังโชว์ข้อมูลครบ

| ชิ้น | ค่าเริ่มต้นของการติดตั้งใหม่ |
|---|---|
| สัญลักษณ์เกจ | เปิด |
| เปอร์เซ็นต์โควต้า | เปิด |
| ป้ายเอเจนต์ | เปิด |
| เปอร์เซ็นต์วันนี้ | ปิด |
| เงินที่เหลือ | ปิด |
| ยอดเกิน | ปิด |

ผู้ใช้ที่เคยเปิดแอปแล้ว ค่าสี่สวิตช์เดิม (เอเจนต์, โควต้า, วันนี้, ยอดเกิน) คงตามที่บันทึกไว้ สวิตช์สัญลักษณ์เกจและเงินที่เหลือเป็นคีย์ใหม่

ปิดทุกสวิตช์แล้วเหลือสัญลักษณ์เกจอันเดียว ถ้ายอดเกินถูกปิด ตัวเลขยอดเกินไม่ขึ้นบนแถบ แต่เปอร์เซ็นต์โควต้ายังเป็นสีแดงเมื่อใช้เกิน 18% บนแถบคือการใช้วันนี้ตามเวลาเครื่อง

## แผงหลัก

กว้างพอดีเนื้อหา ประมาณ 280–300 พิกเซล เรียงจากบนลงล่าง

1. ชื่อ CursorBar กับชื่อแพลน
2. ช่วงรอบบิลกับจำนวนวันก่อนรีเซ็ต ตามเวลาเครื่อง
3. ป้ายโซนเวลาของเครื่อง เช่น `วันนี้ตาม GMT+7`
4. ตัวเลขหลัก: เงินที่เหลือ แล้วบรรทัดใช้ไป / วงเงิน แพลนไม่จำกัดใช้คำว่าไม่จำกัดแทนจำนวนเงิน ทั้งบนแผงและบนเมนูบาร์
5. ช่องเท่าที่มีข้อมูล: วันนี้, Composer, API, เอเจนต์ ช่องเอเจนต์มีเสมอ ที่เหลือไม่ขึ้นเมื่อเซสชันไม่มีค่านั้น
6. สามโมเดลที่ใช้งบสูงสุดในรอบบิล
7. รายการเอเจนต์ที่รอให้ตอบ กดแล้วเปิดใน Cursor
8. ท้ายแผง: เวลาที่อัปเดต, ตั้งค่า, รีเฟรช, ออก

รีเฟรชเป็นปุ่มแคปซูลกระจก ตั้งค่ากับออกเป็นปุ่มตัวอักษร

โชว์เมื่อเซสชันมีค่าเท่านั้น ไม่ใส่แถวว่าง

- ประโยคสถานะจาก `autoModelSelectedDisplayMessage` และ `namedModelSelectedDisplayMessage` วางใต้ตัวเลขหลัก แสดงข้อความต้นทาง ไม่แปล
- ยอด on-demand ของทีม จาก `teamUsage`
- รายละเอียดยอดเกินโควต้า แบบที่แอปมีอยู่
- โทเคนรอบนี้กับตลอดชีพ เมื่อโปรไฟล์สาธารณะอ่านได้

ชื่อเอเจนต์และเหตุผลที่รอให้ตอบเป็นภาษาต้นทางจาก Cursor

## ตั้งค่า

กดตั้งค่าแล้วแผงเดิมเปลี่ยนเป็นหน้าตั้งค่า ไม่เปิดหน้าต่างใหม่

- ภาษา: ตามระบบ, ไทย, English ค่าเริ่มต้นคือตามระบบ จำค่าไว้ สลับแล้วป้ายทั้งแอปเปลี่ยนทันที
- สวิตช์เมนูบาร์หกรายการด้านบน พร้อมตัวอย่างแถบในหน้าตั้งค่า
- ตรวจอัปเดต
- ปุ่มเสร็จ กลับไปแผงหลัก

## ภาษา

มีข้อความสองชุด คือไทยกับอังกฤษ ไม่มีภาษาอื่น โหมดตามระบบใช้ภาษาของ macOS ถ้าไม่ใช่ไทยให้ใช้อังกฤษ วันที่ ตัวเลข และสกุลเงินใช้ตัวจัดรูปแบบของระบบ เป็นดอลลาร์สหรัฐเหมือนเดิม

## เวลา

ใช้ `TimeZone.current` ของเครื่องทุกจุดที่เกี่ยวกับวัน

- วันนี้และงบรายวัน เริ่มที่เที่ยงคืนของเวลาเครื่อง จบที่เวลาปัจจุบัน
- วันที่รอบบิล วันก่อนรีเซ็ต และเวลาที่อัปเดต แสดงตามเวลาเครื่อง
- โทเคนรายวันจากโปรไฟล์ นับวันตามเวลาเครื่อง เลิกเทียบวันเป็น UTC
- วันทำการของงบรายวันยังเป็นจันทร์ถึงศุกร์ตามปฏิทินเครื่อง
- ไม่มีตัวเลือกโซนเวลาในตั้งค่า เครื่องเปลี่ยนโซนเมื่อไร รอบรีเฟรชถัดไปใช้โซนใหม่

## ข้อมูลจากเซสชัน

ใช้เซสชันในเครื่องที่มีอยู่แล้ว ไม่เรียก API ทางการที่ต้องใช้คีย์

- `GET /api/usage-summary` สำหรับแพลน รอบบิล โควต้า Composer API on-demand และประโยคสถานะ
- `POST /api/dashboard/get-filtered-usage-events` สำหรับยอดวันนี้และสามโมเดลของรอบบิล
- โปรไฟล์กับหน้าโปรไฟล์สาธารณะ สำหรับโทเคนรอบนี้กับตลอดชีพ
- ไฟล์ในเครื่องสำหรับจำนวนเอเจนต์และรายการที่รอให้ตอบ เหมือนเดิม

สามโมเดลของรอบบิลรวม `chargedCents` แยกตามชื่อโมเดล ตั้งแต่ต้นรอบบิลถึงตอนนี้ ดึงหน้าละ 100 รายการ สูงสุด 20 หน้า ถ้ายังไม่ครบรอบบิล ให้แสดงสามอันดับจากรายการที่ได้มา ไม่แสดงคำเตือนเพิ่ม

ไม่ใช้ `GET /api/usage` ไม่แสดงบันทึกรายการทั้งก้อน ไม่ทำฮีตแมปโทเคน และไม่แยกบรรทัดของเอเจนต์เบื้องหลัง

## สิ่งที่ไม่ทำ

- ไม่เปลี่ยนไอคอนแอปใน Dock
- ไม่เรียก Admin API, Analytics API หรือ Cloud Agents API
- ไม่เพิ่มปุ่มสลับโซนเวลา
- ไม่เปลี่ยนความถี่รีเฟรช 5 นาที และคำสั่ง `--status`

## การตรวจ

- ติดตั้งใหม่: เมนูบาร์เป็นเกจกับเปอร์เซ็นต์โควต้า และป้ายเอเจนต์เมื่อมีงานรอตอบ
- เปิดครบหกสวิตช์แล้วแถบยาวขึ้น ปิดหมดแล้วเหลือเกจ
- ภาษาไทยกับอังกฤษสลับป้ายทั้งแผง ชื่อเอเจนต์ไม่ถูกแปล
- วันนี้เปลี่ยนเมื่อถึงเที่ยงคืนของเวลาเครื่อง ไม่ใช่เที่ยงคืน UTC
- แผงโชว์เงินที่เหลือ สี่ช่อง สามโมเดล และรายการรอตอบเมื่อมีข้อมูล
- บัญชีที่ไม่มีทีม ไม่มีประโยคสถานะ หรือไม่มียอดเกิน ไม่มีแถวว่างของเรื่องนั้น
